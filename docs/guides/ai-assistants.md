# AI coding assistants

The repository's `context7.json` points Context7 at `docs/` on the `master`
branch. The library identifier is:

```text
/hj-n/zadu
```

Follow the
[Context7 installation instructions](https://github.com/upstash/context7#installation)
for your editor or assistant. Check retrieved examples against the installed
ZADU version: the configured branch can contain changes newer than a release,
and the configuration does not establish when Context7 last refreshed its index.

Repository coding agents should also read
[`AGENTS.md`](https://github.com/hj-n/zadu/blob/master/AGENTS.md). It contains
the repository's requirements for implementing and testing a distortion measure.
