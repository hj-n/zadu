# AI coding assistants

ZADU is indexed for Context7 so coding assistants can retrieve current API
documentation and examples. The library path is:

```text
/hj-n/zadu
```

Follow the
[Context7 installation instructions](https://github.com/upstash/context7#installation)
for your editor or assistant. If the client supports persistent rules, a rule
can ask it to consult Context7 whenever it needs ZADU API or configuration
information.

Repository coding agents should also read
[`AGENTS.md`](https://github.com/hj-n/zadu/blob/master/AGENTS.md). It contains
the correctness, attribution, validation, and execution-DAG requirements for
adding a distortion measure. Contributors themselves only need to provide a
paper and, when available, a reference implementation.
